PROPERTY MAP — FREE IPHONE HOME SCREEN WEB APP

Features: property records, map markers, map point picking, GPS, photos, search and delete.
Data is stored locally in this browser on this device. No cloud sync is configured.
HTTPS is required for GPS, service workers and installation. Map tiles require internet.

To publish: Open repository Settings > Pages. Choose Deploy from a branch, select main and /(root), then Save. Wait for GitHub Pages to publish.
On iPhone: open the published HTTPS address in Safari, tap Share > Add to Home Screen > Add.

Privacy note: this is local browser storage, not a secure vault. Clearing website data can delete properties/photos. Back up important records separately.
